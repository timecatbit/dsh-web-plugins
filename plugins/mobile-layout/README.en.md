# DSH Mobile Layout

A layout-only derivative of [jasondu/dsh-ui-mobile](https://github.com/jasondu/dsh-ui-mobile) 0.1.8, targeting DeepSeek Harness **0.2.1-rc.5 and 0.2.2-rc.1**. It can be installed without the Passkey Proxy. It keeps DSH's own web entry and does not register an additional PWA worker, install prompt, or Web Push.

Follow the [installation guide](https://github.com/timecatbit/dsh-web-plugins/blob/main/README.en.md#installation) to install the package into the profile used by `dsh web`, then restart that process. The Electron desktop app is not supported. Safari can [save the website to your Home Screen or Dock](https://github.com/timecatbit/dsh-web-plugins/blob/main/README.en.md#save-the-website-as-an-app-in-safari). The layout is primarily for viewports narrower than 768 CSS pixels. This package retains the upstream plugin ID. See [LICENSE](LICENSE) for attribution.
