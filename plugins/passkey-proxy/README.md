# DSH Passkey Proxy

为 DeepSeek Harness 提供局域网代理、密码登录和 HTTPS Passkey。可独立使用。保留已安装的包名 `@smanx/dsh-proxy`，更新后继续使用同一份代理设置和凭据。

安装、更新和配置见 [DSH 插件指南](https://github.com/timecatbit/dsh-web-plugins#安装与更新)。本仓库分发可直接安装的构建包；[源码和构建脚本](https://github.com/timecatbit/dsh-web-plugins/tree/main/plugins/passkey-proxy)在主仓库维护。

Based on [smanx/dsh-proxy](https://github.com/smanx/dsh-proxy). See [LICENSE](LICENSE) and [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
