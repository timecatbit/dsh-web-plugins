The official DeepSeek Harness desktop app can now use both plugins. Open **Plugins → Add plugin** in its sidebar and enter a release tarball URL or absolute local path. Standalone `dsh web` installation still works. See the [installation guide](https://github.com/timecatbit/dsh-web-plugins#安装).

- Passkey Proxy `0.1.7-passkeys.4` follows Desktop's current loopback port and keeps its settings separate from standalone Web. Desktop requires an explicit opt-in for LAN binding and automatic entry after proxy sign-in.
- Mobile Layout `0.1.8-mobile.15` includes Desktop installation guidance and retains the same narrow-screen layout.
- Tested on official macOS Apple Silicon Desktop `0.2.2-rc.1` and standalone Web `0.2.1-rc.5` / `0.2.2-rc.1`. Windows Desktop is untested.
